# Momentum - Store-Release: Verlauf

Stand: 16. Oktober 2026

## Zweck

Dieses Dokument hält später fest, welche Entscheidungen und Prüfungen direkt vor
dem ersten öffentlichen Release getroffen wurden.

## 16. Oktober 2026 – Von Phase 21 auf Phase 22 verschoben

Die neue [Phase 21](../phase_21_test_improvements/README.md) bündelt Ausarbeitung und Umsetzung der Testergebnisse. Deshalb wird die bisherige Store-Vorbereitung als Phase 22 weitergeführt. Ihr fachlicher Umfang bleibt bestehen; der Release beginnt erst nach Bearbeitung der ausgewählten kritischen Testergebnisse. Die Store-Vorbereitung selbst ist noch nicht begonnen.
