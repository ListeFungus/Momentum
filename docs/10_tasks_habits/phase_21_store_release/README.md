# Momentum – Phase 21: Store-Release vorbereiten

Stand: 21. Juli 2026  
Status: Geplant

## Zweck

Diese Phase bereitet den ersten öffentlichen Release vor. Sie beginnt erst nach
der privaten Nutzung/Testphase und soll klären, ob die App wirklich in den Store
gehen kann.

## Dokumente

- [Arbeitsplan](store_release_plan.md)
- [Verlauf](store_release_history.md)

## Einordnung

In dieser Phase werden keine fachlichen Aufgaben-/Habit-Grundlagen mehr
erfunden. Stattdessen werden Releasefähigkeit, Distribution, Store-Auftritt,
Paywall-Entscheidung und letzte Pflichtkorrekturen geprüft.
