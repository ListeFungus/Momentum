# Momentum – Phase 19: Firebase-Synchronisierung vorbereiten

Stand: 8. Oktober 2026  
Status: Abgeschlossen

## Zweck

Diese Phase bereitet das Aufgaben-/Habit-Datenmodell auf spätere
Firebase-Synchronisierung vor. Sie folgt nach dem erweiterten Eingabemodell,
damit wichtige lokale Datenformen vorher bekannt sind.

Umgesetzt sind kleine lokale Schema-Ergänzungen, nachvollziehbare echte Änderungen
und das Erhalten von Kartenanzeige-Rücksetzungen. Die App bleibt offline nutzbar.
Cloud-Anbindung, Konten und Konfliktoberfläche gehören zu einer späteren Phase.
Der Arbeitsplan enthält die bestätigten Produktregeln, den Abschluss aller vier
Umsetzungspakete und die ausgeführten Abnahmen. Die echte Cloud-Synchronisierung
bleibt eine spätere Anschlussphase.
