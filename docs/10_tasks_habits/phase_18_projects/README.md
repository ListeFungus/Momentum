## Einordnung

Projekte sind für den ersten Release relevant, weil Aufgaben bereits
Projektzuordnungen speichern können und der Code schon erste Projektansichten
enthält. Diese Phase macht daraus eine bewusst abgeschlossene Produktfähigkeit
statt eine lose vorbereitete Struktur.

Die Pakete 18a–18e sind in Schema 21 umgesetzt. Projekte besitzen Archiv und
Papierkorb, Aufgaben/Habits und Bündel eine gemeinsame historische Zuordnung,
und Übersicht sowie Zeitraum-Auswertung sind angebunden. Details und Prüfstand
stehen im Arbeitsplan und Verlauf.
